# Готовый пакет для ИИ-дизайнера презентации

Передайте ИИ весь архив `akim-presentation-kit.zip` и сообщение:

> Собери презентацию «Аким на 5 часов» по AI_MASTER_PROMPT.md и SLIDE_PROMPTS.md. Используй настоящие снимки из images/ и проверенные сведения из PROJECT_FACTS.md. Основная часть — 7 слайдов, ещё 2 слайда в резерве. Нужны оформленные слайды и заметки выступающего. Не перерисовывай интерфейс и не выдумывай показатели. При противоречиях сначала сообщи о них. Если не умеешь создавать презентации, выдай точный макет каждого слайда и готовый текст без обещания создать файл.

## Что внутри

- `AI_MASTER_PROMPT.md` — общее задание ИИ-дизайнеру.
- `SLIDE_PROMPTS.md` — отдельное готовое задание для каждого слайда.
- `PROJECT_FACTS.md` — проверенный контекст и ограничения.
- `SPEAKER_NOTES.md` — текст выступления.
- `SCREENSHOT_GUIDE.md` — содержание и условия каждого снимка.
- `README_INSERTS.md` — материал для автора README; сам README не изменялся.
- `images/` — настоящие JPEG-снимки работающего приложения.

Если сервис не принимает ZIP, распакуйте его и прикрепите Markdown-файлы и нужные изображения отдельно. Для короткой презентации достаточно основных снимков, перечисленных в SLIDE_PROMPTS.md. Не пытайтесь вместить все снимки на слайды.

Исходный проект находится в репозитории, но внешний ИИ не должен предполагать, что имеет к нему доступ. Пакет самодостаточен. В архив не включаются исходный код, `.env`, ключи, виртуальное окружение или пользовательские переписки.

## Перед отправкой жюри

- Прочитайте финальный текст и проверьте числа по PROJECT_FACTS.md.
- Сохраните читаемыми Score, названия условий и источник карты на снимках.
- Вставьте имя команды и участников сами: в пакете они не выдуманы.
- Слайды развития явно отделите от уже работающих возможностей.
- Не заявляйте, что продукт прогнозирует реальную дорожную обстановку или прошёл внедрение в акимате.
