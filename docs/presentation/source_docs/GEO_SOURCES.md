# Источники границ районов Астаны

`data/astana_districts.geojson` содержит **шесть реальных полигонов административных отношений OpenStreetMap**, включая Сарайшык. Они собраны из исходных OSM ways: вершины не упрощались, не передвигались и не дорисовывались. Старые схематичные полигоны заменены.

Это общественный картографический источник, **не юридически заверенные границы**. Дата загрузки не означает, что все изменения административных границ уже внесены в OSM. Для юридического применения нужна отдельная сверка с действующим актом акимата.

- Загружено: **2026-09-23 11:28:06 UTC**. Время зафиксировано по сохранению исходного HTTP-ответа сразу после скачивания.
- Состояние базы Overpass: **2026-09-22 08:45:51 UTC** (`osm3s.timestamp_osm_base`).
- API: [Overpass](https://overpass-api.de/api/interpreter); полный URL запроса находится в `metadata.source_url` итогового файла и `_provenance.source_url` кэша.

## Файлы источников

- `data/geo_sources/astana_districts_overpass.json` — исходный ответ Overpass и добавленный объект `_provenance`. Это кэш для воспроизводимой сборки. В ответе также есть соседние районы; загрузчик выбирает шесть явно заданных relation ID.
- `data/geo_sources/overpass.json` — первоначально сохранённый ответ того же запроса без добавленной метаинформации.
- `data/geo_sources/sara_osm.json` — дополнительная проверка Сарайшыка через [OSM API](https://api.openstreetmap.org/api/0.6/relation/19733918/full.json).
- `data/geo_sources/sara_nominatim.json` — геометрия того же отношения через [Nominatim](https://nominatim.openstreetmap.org/lookup?osm_ids=R19733918&format=jsonv2&polygon_geojson=1). Она топологически совпадает с собранным полигоном Сарайшыка.

Исходный запрос:

```overpass
[out:json][timeout:25];
rel["boundary"="administrative"]["admin_level"~"^(5|6|7|8|9)$"](50.90,71.0,51.5,72.0);
out geom;
```

## Проверки

На сохранённом результате выполнены проверки Shapely:

- Все шесть геометрий валидны; все кольца замкнуты.
- Все 15 пар районов проверены: площадных перекрытий нет. Общие линии границ допустимы.
- Все исходные вершины граничных ways сохранены с точностью источника. Искусственные точки не добавлены.
- Геометрия Сарайшыка совпадает с геометрией Nominatim; площадь симметрической разности равна нулю.
- Координаты — WGS 84, порядок `[долгота, широта]`; внешние кольца ориентированы против часовой стрелки, внутренние — по часовой.

Эти проверки подтверждают целостность геометрии и отсутствие взаимных площадных перекрытий, но не юридическую актуальность или совпадение объединения районов со всей современной территорией города.

## Контракт для интерфейса

Каждый feature содержит `properties.id`, `name`, `name_full`, `source`, `osm_id`, `source_url`, `retrieved_at`, `osm_names`, `osm_admin_level`, `geometry_status`, `scoring_enabled`, `area_km2`, `center_lon`, `center_lat`.

`source="osm"`, `geometry_status="osm_community_boundary"`. Поля `osm_timestamp` и `osm_version` могут быть `null`: исходный запрос `out geom` их не возвращал; будущий онлайн-запрос `out meta geom` сохранит доступные значения.

**Сарайшык отсутствует в пятирайонном расчётном наборе ТЗ.** У него `scoring_enabled=false`: показывать географический район можно, приписывать ему D, Score или показатели соседнего района нельзя. Модельные данные остальных районов остаются данными ТЗ и не пересчитываются автоматически под новые картографические границы.

`area_km2` — приблизительная геометрическая площадь с простой поправкой на широту (`area_method`), а не число из официальной статистики или движка. `center_lon/center_lat` — центр крупнейшего полигона для подписи, не административный центр.

## Обновление

```bash
python -B fetch_districts.py --offline
python -B fetch_districts.py --source-json data/geo_sources/astana_districts_overpass.json
python -B fetch_districts.py --timeout 40 --max-time 120
```

Первые две команды работают без сети и собирают файл из настоящего сохранённого ответа OSM. Третья обновляет данные через Overpass; для неё нужен `requests`. Для полной проверки топологии загрузчик использует `shapely`, если он установлен; иначе явно сообщает, что выполнены только проверки колец и координат. Shapely не нужен для запуска готового приложения.

Если сеть недоступна, геометрия неполна, район отсутствует или обнаружено пересечение, загрузчик возвращает ошибку и **сохраняет предыдущий GeoJSON**. Схематичная подмена больше не создаётся.
