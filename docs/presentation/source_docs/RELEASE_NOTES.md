# Подготовка к защите: 23 сентября 2026

Этот файл дополняет README, который параллельно ведёт другой разработчик. README, движок, его тесты, исходный расчётный датасет и Git при этой доработке не менялись.

## Что изменено

- Вместо схематичной карты — шесть настоящих полигонов OpenStreetMap. Источники, даты и проверки: [GEO_SOURCES.md](GEO_SOURCES.md).
- Сарайшык добавлен на карту и в обзор. Он серый и без D: в датасете ТЗ для него нет показателей. Размещение проектов остаётся доступным в пяти модельных районах. Выдуманных долей населения или Score нет.
- Карта переключается между оценкой D и десятью показателями. «Риски и компромиссы» показывает разгрузку дорог до/после и отрицательные эффекты мер. Это районная модель, не прогноз трафика на отдельных улицах.
- Клик по району автоматически подставляет его в новые районные проекты; существующий план сохраняет свои назначения. Для Сарайшыка селект показывает «нет данных ТЗ», добавление заблокировано до выбора модельного района. Ручной выбор и подстановка сохраняются после F5.
- В шапке есть «Сбросить»: возврат к базовому городу без события, проектов и текущего чата, с очисткой выбора района и слоя карты. Сохранённые планы команд остаются.
- Фактический отчёт советника формирует код из ответа движка; LLM вызывает инструменты и добавляет качественный комментарий. Числовые предложения модели не становятся расчётными фактами. При ошибке работает полезный офлайн-разбор.
- После F5 восстанавливаются состав, событие, история, проверенные альтернативы и библиотека команд. Сервер пересчитывает результат; готовый разбор повторно используется только при совпадении модели и результата.
- В «Планах команд» есть сохранение, JSON-экспорт/импорт и сравнение до десяти именованных составов. Импорт не доверяет присланным Score или ответам советника.
- «Отчёт» открывает краткую презентацию внутри приложения. Отдельная кнопка вызывает печать / сохранение PDF. Всплывающие окна не нужны.
- Устойчивые планы постоянно подписаны своей базой без события. Применение пересчитывает их в выбранном событии.
- Исправлено наложение плашки события на селектор тематической карты на мобильном экране.
- Проверен запуск через `run.bat`; вывод Python принудительно использует UTF-8, чтобы русские сообщения читались в консоли Windows.
- Разрыв соединения браузером во время запроса обрабатывается без traceback и повторной отправки ошибки в закрытое соединение; HTTP-проверки повторно пройдены.
- Генератор примеров дизайнера обновлён и выполнен; старое описание Streamlit явно помечено как архив.
- Добавлен облегчённый `requirements-lock.txt` с точными версиями активного приложения. Чистая установка подтверждена: [LOCK_VALIDATION.md](LOCK_VALIDATION.md).

## Как запустить

```powershell
.\run.bat
```

Открыть `http://localhost:8501`. Если приложение было запущено до обновления, остановить прежний процесс через Ctrl+C и запустить снова. Браузерную страницу обновить.

Обычные `run.bat` / `bash run.sh` продолжают работать как раньше. Альтернативная облегчённая установка для Python ≥3.12: `python -m pip install -r requirements-lock.txt`, затем `python -B app.py --open`. Launchers автоматически lock не используют.

Для онлайн-советника в локальном `.env` нужны `OPENAI_API_KEY` и `OPENAI_MODEL=gpt-4.1-mini`. `OPENAI_BASE_URL` оставить пустым для OpenAI. Ключ не включать в демонстрацию экрана или публикуемые материалы.

## Сценарий на защите

1. Показать базу **52.56**, бюджет **100**, шесть районов на карте и объяснение пятирайонной учебной модели.
2. «Попробовать план из ТЗ»: **56.54**, **+3.99**, стоимость **95**, критические показатели Нуры устранены.
3. Раскрыть «Как советник пришёл к выводу»: видны реальные simulate и optimize.
4. Сохранить состав как первую команду. Найти обычный оптимум **57.24 / 98**, сохранить как вторую команду и сравнить.
5. Событие «Авария на магистральной теплосети» меняет оценку обычного оптимума на **55.90**. Показать текущую базу события, не подставлять обычные 52.56.
6. В «Сильном буране» найти устойчивый план. Карточка явно показывает обычную оценку **56.83 / +4.27**; после применения в буране — **54.37 / +6.27**, база **48.10**.
7. Переключить слой карты на дороги или школы; открыть «Риски и компромиссы».
8. Обновить страницу: план и готовый разбор сохраняются. Открыть «Отчёт» и предпросмотр презентации.

## Чего не заявляем

- Нет рассчитанного Score Сарайшыка: его показатели отсутствуют в задании.
- Нет прогнозирования заторов на конкретных дорогах, онлайн-трафика или точной длительности перекрытий. Для этого нужны отдельные данные и транспортная модель.
- OSM-границы не являются юридически заверенными; синтетические показатели не превращаются в реальную статистику после замены карты.
- SessionStorage сохраняет вкладку после обновления, а не создаёт серверное хранилище. Для переноса плана используйте JSON.
- Linux/macOS/Docker в этой доработке не запускались. Чистая установка подтверждена на Windows/Python 3.13.2.
- 100 баллов не гарантируются. Предварительная оценка готовности после доработок — около 91/100, зависит от качества защиты и окончательного README.
