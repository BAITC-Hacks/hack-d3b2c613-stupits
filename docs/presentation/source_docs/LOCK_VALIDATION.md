# Проверка requirements-lock.txt перед релизом

Проверено 23 сентября 2026 года на Windows x64, CPython 3.13.2.

Создано новое виртуальное окружение в отдельной папке системного TEMP через `python -m venv`. Установка выполнена только из `requirements-lock.txt`, с публичным индексом `https://pypi.org/simple`; pip использовал доступный кэш wheel-файлов. Рабочее окружение проекта не изменялось.

```text
python -B -m pip install --index-url https://pypi.org/simple -r requirements-lock.txt
Successfully installed ... 32 пакета

python -B -m pip check
No broken requirements found.
```

В этом новом окружении отдельным процессом запущен именно `app.py` на свободном локальном порту. Через настоящий HTTP API проверены:

Эта проверка запуска и контрактов заняла 2,02 секунды; длительность установки в неё не входит. API-ключ и внешний LLM для неё не нужны.

`python -B -m ui.web_check` в том же новом окружении: **14 тестов, OK**.

## Советник и архивные тесты

Полный `python -B -m agent.self_check` в чистом окружении завершился: **38 тестов, OK (skipped=2)**, 3,463 секунды. То есть 36 тестов прошли, два явно пропущены из-за отсутствия Streamlit. Эти два теста зависят от архивного интерфейса:

- `test_conversation_keeps_checked_plan_after_more_than_six_plain_messages` импортирует `legacy.ui.advisor_panel`.
- `test_streamlit_auto_analysis_is_cached_and_invalidated` импортирует `streamlit.testing.v1.AppTest`.

Streamlit намеренно отсутствует в lock активного HTML/API-приложения. Для двух архивных проверок настроен явный пропуск при отсутствии этой библиотеки. Нельзя утверждать, что в минимальном окружении выполнены все 38 проверок: корректная формулировка — **36 passed, 2 skipped**.

Отдельный прогон ровно 36 тестов активного советника также завершился успешно. Прогоны используют настоящий движок и подменённый HTTP-транспорт LLM; это не проверка живого OpenAI API.

## Границы проверки

- Lock закрепляет версии активного приложения, советника, pytest и загрузчиков. Архивный Streamlit, браузерные инструменты разработки и необязательный Shapely не входят.
- Закреплённый NumPy требует Python **не ниже 3.12**. На Python 3.11 этот lock устанавливать нельзя.
- Транзитивные зависимости и маркеры проверены по метаданным для Windows/Linux и Python 3.12–3.14. Фактическая установка и запуск выполнены только на Windows/Python 3.13.2.
- Для Linux, Docker и остальных версий Python результаты запуска здесь не заявлены.
- В lock нет локальных путей и приватных URL. Хэши дистрибутивов не закреплены.
- `run.bat`, `run.sh` и Dockerfile продолжают использовать обычные requirements. Lock применяется отдельной командой установки; автоматически сценарии запуска на него не переключались.
