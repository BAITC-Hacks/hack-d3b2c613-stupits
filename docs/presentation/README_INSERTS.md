# Готовые вставки для README и карта изображений

Корневой `README.md` этим файлом не изменён. Блоки ниже предназначены для ручной вставки в **README в корне репозитория**. Не заменять параллельную работу автора README целиком.

## Какие пути использовать

- В корневом README: `docs/screenshots/01_city.jpg` и аналогично для остальных кадров.
- В отдельном архиве для внешнего ИИ: те же файлы копируются в `images/`, например `images/01_city.jpg`. Это копия для передачи; в README репозитория заменять путь на `images/` не нужно.
- При просмотре непосредственно из `docs/presentation/` относительный путь к оригиналу будет `../screenshots/01_city.jpg`. Ниже намеренно указаны пути для корневого README.
- Все изображения — **JPEG, расширение `.jpg`**. Старые заготовки ссылок `.png` заменить на существующие `.jpg`.

## Проверка плана в кризисе

События меняют исходные условия до применения мер. Сравнивать итог нужно с базой выбранного события. На изображении ниже показан пример ТЗ при аварии теплосети E1: Score 55,21 при базе 51,22, изменение +3,99. Значение 55,90 относится к другому составу — обычному оптимуму при том же событии.

Карта использует шесть настоящих полигонов OpenStreetMap. Расчётный набор ТЗ содержит пять районов. ## Какие устаревшие утверждения заменить

Если они ещё есть в параллельно редактируемом README, заменить:

- «границы схематичные / Overpass недоступен» → настоящие сохранённые полигоны OSM с оговоркой об общественном источнике;
- «Сарайшык показан в составе Есиля / появится позже» → отдельный район карты без показателей ТЗ;
- «основной интерфейс Streamlit» → HTML/CSS/JavaScript, MapLibre и Python HTTP API; Streamlit только в архиве;
- «LLM сама выдаёт подтверждённые числа» → фактический отчёт формирует код, LLM добавляет качественное объяснение;
- «все 38 тестов прошли в минимальном окружении» → 36 passed, 2 skipped;
- «онлайн-соревнование команд / облачное сохранение» → локальное сохранение, JSON-обмен и сравнение;
- «генерация PowerPoint» → встроенный отчёт и печать/PDF.
