## Как использовать без искажения

- Основные кадры уже назначены слайдам в `SLIDE_PROMPTS.md`. Остальные нужны для приложения, README или ответа на вопрос жюри.
- Допустимо увеличить фрагмент реального снимка с сохранением пропорций. Не заменять текст, числа, район или условия внутри снимка.
- Не удалять подпись об условиях события и не представлять серый Сарайшык как район с низким Score.
- При крупном кадрировании карты сохранить атрибуцию OpenStreetMap в подписи слайда.
- Для читаемости используйте один крупный кадр или два крупных фрагмента. Коллаж из всех 16 снимков на одном слайде не нужен.
- Дельты берутся готовыми: показанные округлённые Score нельзя вычитать вместо дельты движка.

Исходники находятся в `docs/screenshots/` проекта. Папка `images/` содержит точные копии этих файлов для передачи внешнему ИИ. Файл `MANIFEST.json` фиксирует размеры и SHA-256 файлов комплекта.
